# Build and deployment reproducibility

## Record these inputs

- Git commit hash.
- `package-lock.json` hash.
- Node and npm versions.
- Hardhat version.
- Solidity compiler version.
- Optimizer and EVM settings.
- OpenZeppelin Contracts version.
- Constructor treasury.
- Target chain ID and RPC endpoints used for observation.

## Clean build procedure

```bash
git clone https://github.com/YOUR_USERNAME/Xiao-Coin.git
cd Xiao-Coin
npm ci
npm run check
```

`npm ci` requires a committed `package-lock.json`, which is generated by the
first trusted `npm install`.

## Suggested release evidence

```bash
node --version
npm --version
git rev-parse HEAD
sha256sum package-lock.json
npm run check
```

Store outputs with the release record. For mainnet, have an independent reviewer
repeat the build on another clean machine and compare the resulting deployment bytecode.
