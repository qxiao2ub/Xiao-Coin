# Xiao-Coin brand guide

## Core identity

- Name: `Xiao-Coin`
- Ticker: `$XIAO`
- Chinese reference: `肖币`
- Tagline: `Small ideas. Big community.`
- Primary themes: community, humor, internet culture, creativity, Base ecosystem.

## Logo

The official repository logo is `web/assets/xiao-coin-logo.png`. Use the logo without
stretching, recoloring, cropping essential text, or adding claims of endorsement.
Maintain clear space around the circular coin.

## Suggested palette

| Role | Hex |
|---|---|
| Deep blue | `#071A52` |
| Base blue | `#175CFF` |
| Bright blue | `#3FA9FF` |
| Gold | `#F7BD2A` |
| Light gold | `#FFE799` |
| Ink | `#071020` |
| White | `#FFFFFF` |

## Naming rules

Use `Xiao-Coin` for the project, `XIAO` for the ticker, and the complete contract
address when authenticity matters. Do not call the project an official Base or
Coinbase coin.
