# Contributing

Contributions are welcome for documentation accuracy, accessibility, translations,
security, and the static website.

1. Open an issue describing the change.
2. Do not change the canonical contract address without verifiable onchain evidence
   and explicit project-owner approval.
3. Do not add price targets, guaranteed-return language, fake partnerships, or
   unaudited security claims.
4. Run `npm run check` before opening a pull request.
5. Keep wallet interactions minimal and non-custodial.
