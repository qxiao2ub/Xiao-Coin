# Contributing

1. Open an issue describing the problem or proposal.
2. Keep version 0.1.0's fixed-supply and no-admin principles intact.
3. Create a focused branch.
4. Add or update tests and documentation.
5. Run `npm run check`.
6. Submit a pull request using the template.

Changes that add minting, taxes, blacklists, upgradeability, arbitrary admin
powers, a sale, yield, price support, or liquidity promises require a new design
proposal and will not be accepted as an undocumented patch.

Never place secrets or personal recovery information in issues, commits, fixtures,
or screenshots.
