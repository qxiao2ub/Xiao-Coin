Xiao-Coin 已通过 Base.meme 创建并上线。本仓库用于发布项目介绍、品牌材料、官方链接、

也不能替代 BaseScan 的链上记录或 Base.meme 的实时交易页面。

## Base.meme Standard 模式

- 8 亿枚 XIAO 用于 Bonding Curve 阶段；
- 2 亿枚 XIAO 预留给后续流动性池；
- Raised Token 为 ETH；
- 当前发行设置使用 2.5 ETH 的 Bonding Curve 募集目标；
- 满足平台毕业条件后，按 Base.meme 当前规则迁移至 Uniswap V4，并锁定对应流动性。

这些是平台机制，不是本仓库对价格、流动性或收益作出的承诺。平台规则、费用和奖励可能变化，
